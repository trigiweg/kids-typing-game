# 打字小勇者

給小學 1～6 年級使用的中英文打字遊戲。字卡從上方掉下來，在落到底之前打對就能消除，闖關拿星星和貼紙。

純網頁、不用安裝、可離線使用，電腦、平板、手機都能玩。

## 怎麼玩

用瀏覽器開啟 `kids-typing-game/index.html`（雙擊檔案即可）。

1. 選年級：初級（1–2 年級）、中級（3–4 年級）、高級（5–6 年級）。
2. 選語言：中文注音或 English。
3. 進入關卡，字卡掉下來時打出上面的字。
4. 通關得到 1–3 顆星和一張貼紙；集滿 5 張解鎖新主題（太空、海底、動物）。

電腦用實體鍵盤，手機和平板點畫面下方的螢幕鍵盤。

### 年級內容

| 級別 | 英文 | 中文（注音） | 愛心 |
|---|---|---|---|
| 初級 | 單一字母、3–4 個字母的單字 | 單一注音符號與簡單音節，不考聲調 | 無 |
| 中級 | 課本常見單字 | 單字注音，不考聲調 | 5 顆 |
| 高級 | 較長單字與短句 | 詞語注音，要打聲調（一聲用空白鍵） | 3 顆 |

### 獎勵與懲罰

- 連續打對有連擊加成：5 連擊起分數 ×2，10 連擊起 ×3。
- 通關依正確率給星星：95% 以上 3 顆，80% 以上 2 顆，其餘 1 顆。
- 打錯只讓連擊歸零。字卡掉到底，中級與高級會扣愛心，愛心用完該關失敗，可以重玩。
- 失敗不扣分，也不會失去已經拿到的貼紙。
- 每天有一次今日挑戰，完成多拿一張貼紙。

### 中文怎麼打

中文使用標準注音鍵盤配置，直接依實體按鍵判斷，不使用系統輸入法，所以不會跳出選字視窗。例如按 `1` 是「ㄅ」，按 `q` 是「ㄆ」，按 `a` 是「ㄇ」。畫面上的注音鍵盤會標出下一個要按的鍵。

## 隱私

- 不需要帳號，不連網，不蒐集任何資料。
- 進度（星星、貼紙、最佳連擊）只存在這台裝置的瀏覽器裡。清除瀏覽器資料就會消失。
- 瀏覽器無法儲存時，遊戲仍可玩，並提醒進度不會保留。

## 專案結構

```
kids-typing-game/
  index.html        遊戲頁面（首頁、關卡地圖、遊戲中、結算）
  style.css         樣式與主題色彩
  tests.html        測試頁（開啟後標題顯示 ALL PASS 代表全部通過）
  js/
    rules.js        連擊、星星、愛心等規則
    keymap.js       注音與英文鍵位
    bank.js         六份題庫（3 個年級 × 中英文）
    session.js      一局遊戲的規則狀態
    input.js        實體鍵盤與螢幕鍵盤的共用輸入入口
    keyboard.js     螢幕鍵盤
    play.js         掉落字卡的畫面與動畫
    storage.js      本機進度儲存
    app.js          畫面切換與流程
docs/spectra/       規格文件（需求與已封存的設計紀錄）
```

沒有使用任何外部套件或建置工具，程式用一般的 `<script>` 載入。

## 測試

用瀏覽器開啟 `kids-typing-game/tests.html`，測試涵蓋規則邊界值、注音鍵位、題庫數量、字卡玩法、輸入處理和進度儲存。

## 開發方式

這個專案用 [Spectra](https://github.com/kaochenlong/spectra-app) 做規格驅動開發，需求與設計紀錄放在 `docs/spectra/`。
