## 2. 輸入與鍵盤提示

- [x] 2.1 [after: 1.1] 依「以實體按鍵（event.code）讀取輸入」建立 Zhuyin key mapping 資料檔，採標準注音鍵位（`Digit1`→ㄅ、`KeyQ`→ㄆ、`KeyA`→ㄇ、`Space`→一聲）。完成後按對應實體鍵即被視為該注音，即使系統輸入法為中文也不出現選字視窗。驗證：測試頁逐一核對全部注音鍵位；手動切到中文輸入法按 1 鍵確認接受 ㄅ。
- [x] 2.2 [after: 2.1] 實作 Only valid keys are processed：忽略不屬於當前模式的按鍵，並對遊戲用到的鍵（含空白鍵）呼叫 `preventDefault`。完成後遊戲中按空白鍵頁面不捲動。驗證：手動在長頁面按空白鍵確認不捲動；在測試頁驗證無效鍵不改變打字進度。
- [x] 2.3 [after: 2.1] 實作 Zhuyin keyboard guide：中文模式顯示注音螢幕鍵盤，英文模式顯示含手指提示的鍵盤，並高亮下一個應按的鍵。完成後作用中的字卡期待 ㄇ 時 `a` 鍵被高亮。驗證：手動試玩兩種模式，確認高亮隨輸入進度移動。
- [x] 2.4 [after: 2.1] 實作 Tone handling：初級題目不含聲調；高級題目須按聲調鍵，第一聲以空白鍵輸入。依「初級不設愛心，聲調只在高級考」的決定出題。驗證：測試頁檢查初級題庫無聲調鍵、高級題庫含聲調鍵；手動以空白鍵完成一張一聲的字卡。

- [x] 4.1 [after: 1.2, 2.2, 3.1] 實作 Falling card gameplay：字卡由上往下掉，輸入完整答案即消除並有視覺與音效；按錯鍵保留已輸入進度並顯示溫和提示；字卡落到底算漏掉。驗證：手動試玩三種情境（打對、打錯、漏掉）；測試頁驗證打錯不改變進度。
