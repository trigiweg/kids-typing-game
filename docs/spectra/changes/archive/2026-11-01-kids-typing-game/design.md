## Context

專案目前沒有任何應用程式碼。目標使用者是小學 1–6 年級學生，使用電腦、平板或手機的瀏覽器，環境可能沒有網路，也不能要求安裝軟體。中文要練的是學校教學用的注音鍵位，所以不能依賴系統輸入法。

## Goals / Non-Goals

**Goals:**

- 在 `kids-typing-game/` 資料夾中提供一個雙擊 `index.html` 就能玩的離線遊戲。
- 支援三個年級級別與中、英兩種模式，並有獎勵與輕量懲罰機制。
- 進度只存在本機，不連網。
- 電腦、平板、手機都能玩：電腦用實體鍵盤，觸控裝置用遊戲內建的螢幕鍵盤。

**Non-Goals:**

- 不做帳號、排行榜、成績匯出、後端。
- 不做系統輸入法的中文自由輸入。
- 不使用建置工具或外部套件。

## Decisions

### 使用傳統 script 標籤而非 ES modules

使用 `<script src>` 載入多個 JS 檔，不使用 `import`。原因：ES modules 在 `file://` 下被瀏覽器擋下，會讓「雙擊就能玩」失效。替代方案是打包成單一巨大 HTML，但這會讓題庫與程式碼難以維護。各檔案用一個全域命名空間 `Game` 掛載模組。

### 以實體按鍵（event.code）讀取輸入

用 `keydown` 事件的 `event.code`（如 `Digit1`、`KeyQ`）對照標準注音鍵位，不用 `event.key`。原因：系統輸入法切到中文時 `event.key` 會變成 `Process`，用 `event.code` 才不受影響。注音鍵位表放在獨立資料檔，英文模式則對照字母本身。

### 題庫為靜態 JS 資料檔

題庫放在 `js/bank.js`（實作時合併進 js 資料夾，不另開 `data/`）以 `Game.bank` 形式載入，每個「級別 × 模式」一份，每份至少 50 題。每題包含顯示文字、答案按鍵序列。注音題另含顯示用的注音符號序列。原因：不需 fetch，`file://` 下可用。

### 進度以單一 localStorage key 儲存 JSON

所有進度存在 key `kids-typing-game:v1`，結構含 `stars`、`stickers`、`themes`、`bestCombo`、`dailyDate`，另存目前選用的主題 `theme`。`themes` 由貼紙數計算（每 5 張解鎖下一個），載入時重算。所有讀寫包在 try/catch，失敗時退回記憶體並顯示提示。key 含版本號，方便日後遷移。

### 規則計算與畫面分離

分數、combo、星星、愛心扣除等規則放在不碰 DOM 的純函式模組，畫面層只呼叫它。原因：規則可以用簡單的測試頁驗證，之後調整數值不用動畫面。

### 初級不設愛心，聲調只在高級考

依討論結論：愛心數量為初級 0、中級 5、高級 3；初級不考聲調，高級才要求聲調鍵，第一聲用空白鍵。

### 畫面採用太空主題設計稿

視覺依已確認的三張畫面設計稿（首頁、遊戲中、過關結算）。設計稿來源與數值見上方「Design Source」。實作時色彩、字級放進 CSS 變數，方便之後換主題（海底、動物）。

### 響應式版面與螢幕鍵盤

版面用 CSS Grid/Flex 搭配 `clamp()` 與媒體查詢，三個斷點：手機（≥360）、平板（≥768）、電腦（≥1280）。螢幕鍵盤是同一份 DOM 在所有裝置顯示：點擊按鍵會呼叫與實體按鍵相同的輸入處理函式（傳入 `event.code` 等價值），因此規則與驗證只有一套。觸控按鍵高度至少 44px、寬度隨螢幕縮放（最窄 28px，手機第一排 11 鍵約 31px），使用 `touch-action: manipulation` 與 `user-select: none` 避免雙擊放大與選取文字。替代方案是手機另做一套介面，但會讓規則與測試加倍。
## Implementation Contract

**行為**：孩子開啟 `kids-typing-game/index.html`，選年級與語言，進入關卡地圖，玩掉落字卡關卡，結束後看到星星與貼紙，進度在重新載入後仍存在。

**介面與資料形狀**：

- 注音鍵位表：物件，鍵為 `event.code`，值為注音符號，採標準注音鍵盤配置（例如 `Digit1`→ㄅ、`KeyQ`→ㄆ、`KeyA`→ㄇ、`Space`→一聲）。
- 題目：`{ id, display, keys: [...] }`，`keys` 為依序要按的 `event.code`。
- 進度 JSON：`{ version: 1, stars: { "<tier>-<mode>-<level>": 0..3 }, stickers: number, themes: string[], bestCombo: number, dailyDate: "YYYY-MM-DD" }`。
- 規則函式：`comboMultiplier(combo)`（<5→1，5–9→2，≥10→3）、`starsFor(accuracy)`（<80%→1，80–94%→2，≥95%→3）、`heartsFor(tier)`（初級 0、中級 5、高級 3）。

**失敗行為**：localStorage 不可用時以記憶體進度繼續，並顯示「進度不會儲存」提示；打錯鍵只給溫和視覺提示；愛心用完只讓該關失敗並可重玩，不扣總分與貼紙。

**驗收**：

- 在 `file://` 開啟，無網路時所有功能可用，開發者工具的網路面板沒有任何請求。
- 系統輸入法切到中文時，按注音鍵仍被正確讀取，且沒有出現選字視窗。
- 規則函式的邊界值（79/80/94/95 百分比、combo 4/5/9/10）有測試頁驗證通過。
- 六種「級別 × 模式」題庫各至少 50 題且不重複。

**範圍界線**：

- 範圍內：`kids-typing-game/` 下的 HTML、CSS、JS、題庫資料、規則測試頁。
- 範圍外：後端、帳號、排行榜、成績匯出、系統輸入法支援、其他專案檔案。

## Risks / Trade-offs

- [注音鍵位對照出錯，孩子練到錯的鍵位] → 鍵位表單獨成檔，並有測試逐一核對標準配置。
- [手機螢幕小，字卡與螢幕鍵盤擠在一起] → 螢幕鍵盤依寬度縮放並固定在底部，字卡區用剩餘高度，手機上以 390×844 試玩調整。
- [愛心與倍率數值玩起來太難或太簡單] → 數值集中在單一設定處，實際試玩後調整。
- [一年級孩子手指找不到鍵] → 鍵盤圖常駐並高亮下一個鍵，初級字卡下落速度放慢。
- [localStorage 被清除，進度消失] → 這是本機儲存的已知限制，首頁不做額外承諾。
